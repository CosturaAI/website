How it works

  1. Connect read-only billing keys

    One key per provider, with the narrowest permission each one offers. Costura reads usage and cost; it never creates, edits or deletes anything.

  2. Get one ledger

    Usage lands in a daily ledger and rolls up to a person: API keys and Cursor, Claude.ai and Codex seats under one e-mail.

  3. Act on what changed

    Anomalies explained in one sentence, budgets, keys without an owner, and a tie-out against each provider's report, in the app or on a webhook.

One story across providers

Anthropic, Claude.ai, OpenAI, Codex, OpenRouter, Cursor and GitHub Copilot (experimental) in a single ledger.

Every person accounted for

Owner, limit, creation date and last use for each key and seat, rolled up to the person who spent it.

Your keys stay with you

Open source and self-hosted. Provider keys are stored encrypted on your infrastructure and never leave it. No telemetry.
