# Costura website

[![CI](https://github.com/CosturaAI/website/actions/workflows/ci.yml/badge.svg)](https://github.com/CosturaAI/website/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-Apache--2.0-blue)](LICENSE)

The source of [costura.ai](https://costura.ai): the website and the blog. It is a
[Hugo](https://gohugo.io) site with no executable JavaScript, published to GitHub Pages.

## Quick start

```sh
mise install
just serve
```

Then open `http://localhost:1313`. `just new <slug>` starts an article;
[CONTRIBUTING.md](CONTRIBUTING.md) has the layout, the recipes, the article steps and
how the site is published.

## Support

Bugs and article proposals go through the issue forms. Questions go to
[Discussions](https://github.com/CosturaAI/website/discussions). Vulnerabilities go through
[SECURITY.md](SECURITY.md). Everyone taking part follows the
[Code of Conduct](CODE_OF_CONDUCT.md).
